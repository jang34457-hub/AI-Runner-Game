# AI 사이버 러너 (AI Cyber Runner) 🏃‍♂️💨

**바이브코딩 실습용 3레인 무한 러닝 HTML5 게임**

---

## 🎮 1. 게임 소개
AI 사이버 러너는 사이버 공간 속에서 캐릭터가 자동으로 전진하며, **바이러스(🦠) 장애물**을 피하고 **백신(💉) 아이템**을 획득하여 생명력을 회복하면서 최고 점수에 도전하는 3레인 액션 러닝 게임입니다.

- **주요 캐릭터**:
  - 🐥 **삐야 (Ppiya)**: 밝고 귀여운 노란색 AI 탐험가 (`삐야.png`)
  - 🛡️ **오르 (Ore)**: 사이버 세계의 흰색 방어자 (`오르.png`)

---

## 🚀 2. 주요 기능 및 특징
1. **3레인 이동 시스템**: Left(0), Center(1), Right(2) 레인 간 부드러운 스무스 이동 (키보드 및 온스크린 버튼 지원)
2. **생명력 & 무적 효과**: 
   - 기본 5개의 생명력 (`❤️❤️❤️❤️❤️`)
   - 바이러스 충돌 시 생명 -1 및 1초간 점멸 무적
   - 백신 아이템 먹으면 생명 +1 (최대 5개 제한)
3. **사이버 매트릭스 배경**: 0101 비트 스트림 및 반투명 프로그래밍 코드 조각 스크롤
4. **난이도 적응**: 거리가 멀어질수록 속도 증가 및 바이러스 무작위 생성 비율 상승
5. **최고 점수 저장**: `localStorage`를 이용한 로컬 최고 기록 유지

---

## 🛠️ 3. 기술 스택 및 구조
- **HTML5 Canvas (2D)**: 게임 엔진 및 실시간 렌더링
- **Vanilla CSS3**: 사이버펑크 네온 글래스모피즘 UI 및 애니메이션
- **Vanilla JavaScript (ES6+)**: JSDoc 주석 적용 및 객체 지향 게임 구조 (`Player`, `Obstacle`, `Vaccine`, `GameEngine`)

### 파일 구조

├── 오르.png          # 오르 캐릭터 이미지

## 💻 4. 실행 방법
1. 별도의 서버 설치 필요 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge 등)로 열면 바로 실행됩니다.
2. 로컬 웹 서버로 테스트하려면:
   ```bash
   npx serve .
   # 또는 파이썬 사용 시
   python -m http.server 8000
   ```
3. 브라우저 주소창에 `http://localhost:8000`으로 접속합니다.

## 🎯 5. 바이브코딩 실습 팁
- `game.js` 내의 `CONFIG.INVINCIBLE_DURATION` (무적시간) 또는 `this.baseSpeed` (기본속도) 값을 변경해 난이도를 자유롭게 조정할 수 있습니다.
- 백신 및 바이러스 외에 자석, 2배 점수 아이템 등 2차 기능 확장이 용이하도록 클래스 구조로 분리되어 있습니다.
